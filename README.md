VICE FRAME is an offline cover studio that turns any photo and a caption into GTA 6-style cover art: a multi-panel collage with a Vice City neon-sunset grade, stacked gradient lettering and an original VI badge, exported as a shareable PNG. It runs entirely in the browser — upload or drop a photo (or use a bundled sample), arrange it across the panels, pick a layout and grade, and export at portrait, square or wide sizes. No uploads, no network, no accounts: your photos never leave your device.

## Run it

```sh
node main.ts
```
